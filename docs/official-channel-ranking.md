# Official channel priority

The shared ranker used by Player, search, and local suggestions compares text relevance first, curated official-channel membership second, karaoke metadata strength third, known views descending fourth, then the karaoke score. The original result order is used only when all five values tie. This is not exact song/artist entity resolution: relevance still uses title/artist/channel text. An official channel must not overtake a stronger query match. Non-karaoke and non-embeddable videos still fail the existing filters.

Never match names, subscriber counts, or words like Official/Original. Recheck entries if ownership changes. The badge means an app-reviewed channel, not certification that every recording is the original master or a license for commercial use.

Browser and server cached results are re-ranked without invalidating cache or issuing a new search. Direct video links bypass ranking. No new runtime API request, paid service, or environment variable is required. Supabase catalog candidate ordering follows the same official, karaoke strength, then views rule. This only changes candidate order; it cannot reveal a video absent from the search results or catalog.
